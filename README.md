# lumiten-legal
Legal Docs for Lumiten

Public legal pages for Lumiten Systems apps, served with GitHub Pages.

| App | Privacy policy |
| --- | --- |
| Vahan Care | https://lumitensystems.github.io/lumiten-legal/vahan-care/privacy/ |

These files are generated — edit the source in `lumitensystems/lumiten-apps`
(`apps/<app>/legal/`), run `node apps/<app>/legal/build.mjs`, and copy `legal/dist/` here.
